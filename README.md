# Mini MVC - Projet d'apprentissage React & PHP

## Description

Ce projet est une application e-commerce développée dans le cadre de mon apprentissage des technologies web modernes. Il combine un **frontend React** avec un **backend PHP** suivant l'architecture **MVC** (Model-View-Controller).

## Ce que j'ai appris

### Frontend - React
- Création de composants React (JSX)
- Gestion du state et des props
- Routing avec React Router
- Gestion du panier d'achat
- Authentification utilisateur (Login/Signin)
- Intégration avec une API REST

### Backend - PHP MVC
- Architecture MVC (Models, Views, Controllers)
- Création d'une API REST
- Gestion de la base de données (MySQL)
- Routing personnalisé
- Intégration de Stripe pour les paiements


## Technologies utilisées

- **Frontend**: React, Vite, ESLint
- **Backend**: PHP, Architecture MVC
- **Base de données**: MySQL
- **Paiement**: Stripe
- **Outils**: Composer, npm

## Installation

### Backend
```bash
cd mini_mvc
composer install
# Configurer la base de données dans les fichiers de configuration
```

### Frontend
```bash
cd mini_MVC_frontend
npm install
npm run dev
```
